UPYOG Automation User Guide

Welcome to the UPYOG Automation Testing Hub. Learn how to configure environments, execute end-to-end test suites, understand testing approaches, and access execution artifacts.

🚀 Quick Start — How to Run Automation 3 Simple Steps
1

Select Environment & URL

Choose your target testing environment from the Base URL dropdown:

  • Upyog Citizen / Employee: Production or standard live portal.
  • Niuatt Citizen / Employee: NIUA staging & testing server.
  • Upyog Sandbox: Dedicated sandbox environment for sandbox validation.
  • Local Host: Local development instance (port 8080).
2

Select Modules & Inputs

Select one or multiple modules from the searchable multi-select dropdown:

  • Use the search bar to quickly find modules (e.g. Pet, Trade License, Street Vending, OBPAS).
  • Default credentials (mobile number & OTP 123456) are automatically populated.
  • OBPAS architect credentials automatically switch based on the selected environment.
3

Execute & Monitor

Click Run Test to start automation and monitor progress:

  • The Live Progress Bar displays real-time completed vs. total test cases.
  • Click Live Screen to watch browser execution via noVNC (http://65.0.8.57:8000), only for Citizen,Employee and Vendor Testing
  • Session video recordings and HTML user manuals are generated automatically.
📗 Excel Data-Driven Testing Custom Test Data

1. Download Template

Download the pre-formatted Excel template configured with the required schema and field headers for all modules.

  • Click Download Excel Template in the Module Testing tab.
  • The downloaded workbook (UPYOG_Test_Data.xlsx) contains structured sheets for each module.

2. Fill Custom Test Data

Customize input values per test case such as mobile numbers, applicant names, property details, and city selections.

  • Set Execution Flag: Keep the Execution column set to YES for all test cases you want to run (rows with NO will be skipped).
  • Fill rows for single or multiple test scenarios.
  • Supports parameterization for multi-module batch regression suites.

3. Upload & Execute

Upload your populated Excel sheet and trigger automated batch execution driven entirely by your test spreadsheet.

  • Click Upload Excel and choose your .xlsx file.
  • Click Run Test to start automation using the custom datasets.
📑 Testing Approaches & Modes Scope Guide

Module Testing

Full End-to-End Flow
Executes complete end-to-end automation covering both Citizen application creation and official Employee scrutiny, approval, and payment collection in a single automated chain.
Workflow Chain: Citizen Form Submission ➔ Application No. Capture ➔ Employee Inbox Search ➔ Verification & Approval ➔ Cashier Fee Payment.
Best for: Full regression testing & release sign-off

Citizen Testing

Citizen Journey Only
Runs only the citizen-facing workflow. Tests citizen login with OTP, multi-step application form filling, document uploads, and application submission to generate an Application Reference Number.
Workflow Chain: Citizen Mobile Login ➔ OTP Verification ➔ Property/Trade/Pet Details Entry ➔ Document Uploads ➔ Acknowledgement Screen.
Best for: Form validation, UI intake testing & citizen journey checks

Employee Testing

Official Workflow Only
Runs the back-office employee workflow on existing applications. Handles role-based employee login, searching applications by number, scrutiny, document verification, forwarding, approval, and cashier payment collection.
Workflow Chain: Employee Username/Password Login ➔ Inbox Search ➔ Application Scrutiny ➔ Take Action (Approve/Forward) ➔ Collect Payment.
Best for: Back-office verification, role actions & cashier payments

Vendor Testing

Agency Operations
Runs vendor and service provider fulfillment workflows for on-demand municipal services such as Water Tanker Booking, Mobile Toilet Delivery, and Construction & Demolition (C&D) Waste collection.
Workflow Chain: Vendor Authentication ➔ Service Request Queue ➔ Verification & Vehicle Assignment ➔ Request Fulfillment.
Best for: Third-party agency workflows & service dispatch verification
📊 Execution Artifacts & Reports Outputs

Extent Test Reports

Access comprehensive, interactive HTML reports with step-by-step logs, exact execution timestamps, pass/fail status, and embedded base64 error screenshots for quick debugging.

Visual User Manuals

Automatically generated documentation featuring high-resolution step screenshots, step descriptions, an interactive workflow filter bar (filter by test case), and delete buttons for removing unnecessary images.

Screen Video Recordings

Watch session screen recordings in the built-in HTML5 video player modal. Browse all recorded clips from your test session, download individual MP4 files, or download complete ZIP packages.

Helpful Tips for Seamless Execution

• Excel Execution Flag: In the test data spreadsheet, keep the Execution column set to YES to execute those test cases (rows set to NO are automatically skipped).
• OTP Autofill: Default OTP is 123456 for testing environments.
• Multi-Module Batch Execution: You can check multiple modules in Module Testing to execute an entire regression suite automatically.
• Live Browser Screen: If running on the remote server, open http://65.0.8.57:8000 in a new tab to view the live Selenium browser session in real time.
• Artifacts Retention: Screen recordings and screenshots are maintained temporarily and can be exported as ZIP bundles anytime from the Test Reports tab.
